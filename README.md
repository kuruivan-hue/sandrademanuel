# Sandra de Manuel — Arte Flamenco

Landing page y portfolio oficial para la bailaora de flamenco **Sandra de Manuel**, diseñado con una estética oscura, minimalista y arquitectónica inspirada en el sistema de referencia Dinamo Sites.

---

## 🎨 Sistema Visual Actualizado

- **Paleta Cromática**:
  - Base: `#0b0c0a` (negro profundo y elegante).
  - Fondos sutiles: `#121310` / `#161714`.
  - Tipografía principal: `#f5f2eb` (blanco cálido / marfil).
  - Tipografía secundaria: `#a6a49c` (marfil suave).
  - Acentos y detalles: `#d4a373` / `#c59b6d` (oro cálido y cobre flamenco derivado del logotipo).
- **Tipografía**:
  - *Instrument Sans*: Titulares contemporáneos e interfaces.
  - *Newsreader*: Cursiva poética para enfatizar nombres y términos flamencos.
  - H1 display: **Sandra *de Manuel***.
- **Geometría**:
  - Divisores finos de `1px` con transparencias cálidas.
  - Radios máximos de `6px`.
  - Sin sombras pesadas, blobs ni cards convencionales.
